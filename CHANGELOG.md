# Changelog

All notable changes to ElasticPDF will be documented in this file.

## [0.9.0] - 2026-08-08

### Web Preview

ElasticPDF v0.9.0 is the first public Web Preview release.

This version brings together PDF reading, text editing, image and graphics editing, annotations, page operations, and document export in a unified browser-based experience.

### Added

#### PDF Reader
- Page thumbnails and bookmark navigation.
- Full-document text search.
- Zoom from 10% up to 6400%.
- Continuous and page-by-page reading modes.
- Single-page, double-page, and book views.
- Horizontal and vertical scrolling.
- Page rotation.
- Light and dark modes.
- Multilingual UI.

#### PDF Text Editing
- Direct editing of existing PDF text without converting to Word.
- Insert, delete, and modify text.
- Automatic text reflow when content changes.
- Resize and reposition text blocks.
- Edit rotated, vertical, and angled text.
- Bold, text color, and alignment controls.
- Styled copy and paste.
- Multilingual text editing.
- Preserve original fonts, styles, positions, and layout where possible.
- Export edited content back to standard PDF.

#### Image & Graphics Editing
- Directly select and edit existing PDF images and graphics.
- Move, resize, and rotate objects.
- Crop and replace images.
- Flip images horizontally or vertically.
- Adjust opacity.
- Precisely control object size.
- Manage layers.
- Bring objects to front or send them to back.
- Save original images locally.
- Delete selected objects.

#### PDF Annotations
- Highlight, underline, strikethrough, and squiggly annotations.
- Freehand drawing.
- Callouts and sticky notes.
- Text boxes and image annotations.
- Stamps and handwritten signatures.
- Edit annotation position, range, color, line width, line style, opacity, and other properties after creation.

#### Shapes & Markup
- Rectangle, circle, ellipse, line, arrow, polygon, polyline, and arc annotations.
- Hyperlink editing.
- Edit position, size, rotation, border, fill, line style, arrow endpoints, and path nodes after creation.

#### Page & Document Operations
- Add pages.
- Delete pages.
- Merge pages.
- Export documents.
- Save edited PDFs.

#### Privacy & Platform
- Browser-side PDF processing for normal reading and editing workflows.
- Support for major modern browsers.
- Cross-platform architecture designed for Web, desktop, and mobile integration.

### Notes
- This release focuses on the ElasticPDF Web experience.
- Desktop and mobile applications are still under development and improvement.
- v0.9.0 is published as a Web Preview rather than the final v1.0.0 release.
